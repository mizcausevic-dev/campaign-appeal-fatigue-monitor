# Security Notes

`campaign-appeal-fatigue-monitor` publishes synthetic nonprofit outreach and stewardship data only.

It does **not** contain:

- live donor records
- production fundraising platform credentials
- real campaign send schedules
- proprietary audience segmentation logic
- real appeal or stewardship packets

This repo is a public operator-surface proof for nonprofit and foundation operations. It is not a fundraising compliance or donor privacy certification claim.
